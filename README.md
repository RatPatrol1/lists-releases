# Lists for Android: downloads

Lists is a simple shopping-list app for Android that makes it hard to lose items by accident.

- **Tap** an item to cross it off. It stays readable.
- **Swipe** an item to save it for later.
- **Long-press** an item to edit it or attach photos.
- **Send** a list as a text message, one item per line.
- **Delete** whole lists or crossed-off items from each list's tools menu. Every delete asks first and can be undone.

This repository holds only the app's releases.

## Install

1. On your Android phone (Android 10 or newer), open **<https://github.com/RatPatrol1/lists-releases/releases/latest>**.
2. Under **Assets**, tap `Lists-x.y.z.apk` to download it.
3. Open the downloaded file. The first time, Android asks you to allow installs from your browser. Allow it, then tap **Install**.

## Updates

The app checks for new versions once a day. You can also check from **⋮ → Check for updates**. When an update is available, tap **Update**. The first time, Android asks you to allow "Install unknown apps" for Lists. Your lists and photos are kept.

Always install Lists from this page. A copy from anywhere else can't be updated without uninstalling first, and uninstalling erases your lists.
